Nod API playground

Open an endpoint, select Try it out, edit the request, then Execute.

  1. Use auth/login/ with your account, or register and verify your email first.
  2. Run reviewers/list/, copy a reviewer's ID, and use it in submissions/create/. Generate a fresh client_request_id UUID for each new submission.
  3. Log out, log in as the assigned reviewer, and use submissions/decision/{id}/ to approve or reject.

Session cookies and CSRF are handled automatically, including after login. The Authorize dialog is not needed. Requests change real data on the current server.
